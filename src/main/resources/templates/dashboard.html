Where AEGIS draws the line

Does
  • Logs every Qusar decision independently of the agent's own logs
  • Flags fraud signals and statistical denial outliers
  • Tags which jurisdiction's disclosure standard applies
  • Maps flagged decisions to exposure categories
  • Exports an audit bundle a human can act on
Deliberately doesn't
  • Replace Qusar's own agent-level governance
  • Certify that a decision is compliant
  • Make a legal coverage determination
  • Set or adjust a premium
  • Move money or write back into PolicyCenter / ClaimCenter
No live Qusar sandbox. A mock generator emits decisions in the exact shape a Qusar agent log would take, through the same POST /api/decisions path — swapping in a real feed touches one adapter, nothing downstream.
