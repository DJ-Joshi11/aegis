Detection & Compliance

The instant a decision is persisted, two rules decide whether it needs a second look. Flagged decisions are tagged with the disclosure standard their jurisdiction calls for — a pointer for a human reviewer, never a certification that the decision passes it.

Always-flag fraud referrals

Rule 2

Denial-rate outlier

0fired

An agent that denies far more than it approves is a bias signal. Once it has enough history, each further denial above the threshold gets flagged.

if outcome == "DENIED" and agent.total ≥ 5 and agent.denials / agent.total > 50%
  → flag, reason = "Denial rate for {agent} is X% over N decisions"
