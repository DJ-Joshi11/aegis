Ingestion

Every decision a Qusar agent makes lands here first. AEGIS validates it, persists an immutable audit row that lives outside the agent's own logs, and publishes it to detection — synchronously, in the same request.

POST/api/decisions
01 · RECEIVE
Decision event arrives

From a live Qusar feed or the mock generator — same endpoint, same DecisionEvent shape.

02 · VALIDATE
Normalise & check

Trims fields, fills a UUID / timestamp if blank, requires agent, type, outcome, jurisdiction, reasoning.

03 · PERSIST
Immutable audit row

Saved to decision_audit. A duplicate decision ID is rejected with a 400 — nothing gets logged twice.

04 · PUBLISH
Hand off to detection

Published as an in-process Spring event. Detection and evidence mapping react before the HTTP response returns.
